# Бібліотека

“Бібліотека” – це сучасна вебплатформа, розроблена для полегшення доступу до книжкового каталогу, взаємодії з літературою та управління бібліотечними процесами. Проєкт орієнтований як на звичайних користувачів, так і на бібліотекарів/адміністраторів.

## Основні можливості

- Перегляд популярних, нових та випадкових книг.
- Фільтрація каталогу за видавництвом, мовою, типом книги.
- Пошук книг за назвою.
- Сортування книг за популярністю та новизною.
- Перегляд профілю користувача, редагування даних, перегляд закладок, бронювань, позичень.
- Додавання книги до закладинок та бронювання книги.
- Додавання авторів та видавництв.
- Редагування та видалення книг.
- Обробка бронювань: підтвердження або скасування.


## Установлення

Для локального розгортання вебзастосунку:

### Клонування

```bash
  git clone https://github.com/BoshkaS/Library.git
```

### Підготування проєкту до запуску
При відкритті проєкту натисність F5.

Завантаження біблотек для фронтенду

```bash
  cd .\Library\Client\
  npm install
```

Оновіть appsettings.Development.json у ASP.NET Core проєкті та придумайте Token Key, не менше 70 символів:

```bash
  "ConnectionStrings": {
  "DefaultConnection": "Host=localhost;Port=5432;Database=mydb;Username=myuser;Password=mypassword"
},
"TokenKey": "super secret unguessable key"
```

Створіть базу даних у pgAdmin та зробіть міграції
```bash
cd ..
dotnet ef migrations add Initial
dotnet ef database update
}
```

### Запуск проєкту
Бекенд
```bash
dotnet run
}
```

Запуск модельки для пошуку схожих книг
```bash
cd .\Library\Python_API\
pip install uvicorn fastapi
pip install sentence-transformers
pip install psycopg2
pip intall dotenv
}
```

Фронтенд
```bash
cd .\Library\Client\
npm start
}
```
